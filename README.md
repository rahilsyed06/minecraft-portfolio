# Syed Rahil — Minecraft Portfolio

Static, single-page Minecraft-themed portfolio: `index.html`, `style.css`, `script.js`. No build step and no dependencies.

Steve, the pixel icons and the world are drawn with HTML, CSS and inline SVG, so there are no image files. The pixel font (Press Start 2P) loads from Google Fonts.

## Run locally
Open `index.html`, or run `npx serve .`

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. In Vercel choose Add New -> Project and import the repo.
3. Framework Preset: Other. Leave Build Command and Output Directory empty.
4. Deploy, then add your domain under Settings -> Domains.
